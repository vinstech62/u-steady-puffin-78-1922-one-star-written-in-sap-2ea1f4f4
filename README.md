A one-line 1-star review written by a houseplant about its human owner: the plant gives a single star for being watered with ice cubes, and for an owner who apologizes to its face and then does it all again the next day, as if the apology counts as hydration. Built for make.fun's "One Star, Written in Sap" bounty — a deterministic program that writes the review to /output/entry.txt.

## Run it

```sh
python3 main.py
```
